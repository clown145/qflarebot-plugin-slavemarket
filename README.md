# 奴隶市场 (qflarebot-plugin-slavemarket)

[QFlareBot](https://github.com/QFlareBot/QFlareBot) 的群聊文字游戏：打工赚金币、买卖群友当奴隶、训练、决斗、排位赛、银行、排行榜，每周自动重置。

移植自 Yunzai-Bot V3 插件 [Slave-Market](https://gitee.com/Tloml-Starry/Slave-Market)（作者 Tloml-Starry 及贡献者），玩法、数值和文案与上游一致，存储、出图和指令写法改成了适合 QQ 官方机器人和 Cloudflare Workers 的样子，并修掉了上游的一些 bug（见下文）。

## 安装

面板 → 插件 → 安装插件，粘贴本仓库链接。需要：

- **D1**：所有数据都在 D1 里，不用 KV。
- **内置的 t2i 插件**（打工报告、一键训练、排行榜、市场、帮助出图用）。图存在 T2I 渲染服务上，QQ 直接去拉，图片不经过 Worker；t2i 不可用或渲染失败时自动改发文字。需要 QFlareBot 里 t2i 带 `renderUrl()` 的版本，旧版本同样会退回文字。

## 指令

群里 @机器人 时可以不打 `/`。只能在群里玩。

| 指令 | 说明 |
| --- | --- |
| `/奴隶帮助` | 全部指令（图） |
| `/打工` | 没奴隶自己打工，有奴隶派奴隶去 |
| `/奴隶市场` | 全群的身价和主人，带编号 |
| `/购买奴隶 @群友` 或 `/购买奴隶 市场编号` | 买下群友 |
| `/我的奴隶` | 自己的金币、身价、奴隶列表（带序号） |
| `/放生奴隶 序号` 或 `@群友` | 放走奴隶 |
| `/赎身` | 两倍身价买回自己，身价 ×1.2，另交一笔税 |
| `/抢劫`、`/抢劫 @群友` | 不 @ 就随机挑一个 |
| `/训练 序号` 或 `@群友`、`/一键训练` | 提升奴隶身价 |
| `/决斗 我的奴隶序号 对手` | 对手可以 @，也可以是自己另一个奴隶的序号 |
| `/排位赛`、`/参加排位赛 序号` | 段位与排位赛 |
| `/存款 金额`、`/一键存款`、`/取款 金额` | 银行存取 |
| `/升级信用`、`/一键升级信用`、`/银行信息`、`/领取利息` | 银行等级与利息 |
| `/转账 金额 @群友` | 收手续费 |
| `/奴隶身价排行榜`、`/奴隶资金排行榜`、`/上周排行榜` | 排行榜 |
| `/奴隶重置状态`、`/奴隶重置帮助` | 每周重置 |
| `/手动奴隶重置` | 群主、管理员：清空本群数据（按钮二次确认） |

序号来自 `/我的奴隶`，按买下的先后排，训练、改身价都不会让它变。市场编号按身价从高到低排。

## 与上游的不同

**QQ 官方机器人没有的东西**

- 没有 QQ 号，也拿不到群成员列表：目标一律用 @ 或编号；昵称取消息里带的名字，没有时显示「群友」加 openid 后四位。上游「不在群里就删档」改成监听退群事件（放掉他的奴隶、删掉存档）。
- 没有 puppeteer：出图交给内置 t2i 插件，模板从上游搬过来。
- 没有合并转发：`/我的奴隶` 改成一条文字；`/上周排行榜` 原来连发 6 条（超过被动回复 5 条的上限），合成一张图。
- 去掉了 `#奴隶更新`、`UPDATE.bat`（更新走面板）、备份四件套（D1 本身有 Time Travel）、锅巴配置（改成面板配置）。
- 上游的 Bot 主人打工特权和 `ignoreCDUsers` 改成两个 openid 名单配置：「尊贵的奴隶主」「无视冷却」。

**修掉的 bug**

- 每周重置时排行榜按重置当周的周数存，`#上周排行榜` 却按上一周的周数找：**重置后那一周查不到，再下一周查到的是两周前的数据**，重置后的自动回顾也一样。
- `#手动奴隶重置` 会清空**所有群**的数据，现在只清本群，而且用按钮确认（只有发起人点得了）。
- 从别人手里买奴隶：文案说被买的人「额外获得十分之一」，代码给了全额——按文案改。
- 决斗不管输赢都记一场胜、都发奖励；现在输了记负场、没有奖励（配置本来就叫「获胜奖励」）。
- 排位赛配置里的基础奖励、胜利加成、段位倍率都没用上；现在奖励 = (基础奖励 + |分数变化| × 0.1) × 赛前段位倍率，赢了再 × (1 + 胜利加成)。初始 1000 分却显示「青铜」（自己的段位表里 1000 分是白银），现在段位按分数现算。
- 打工时随机花费的钱扣了没存，也不在报告里；失败文案里「身价下降 X->Y」的 Y 没算 0 封底。
- `#一键存款` 的正则要求后面带数字，单发不触发；超过存储上限时改成存满为止。
- 利息按「现在的存款 × 距上次领取的小时数」算：先存 1 块，等一天再把钱存满，领到的是满额一整天的利息。现在存取款前先把旧余额的利息结出来，新存的钱从存入时起算。
- 抢劫随机目标可能抽到自己（QQ 号是数字、文件名是字符串，比较永远不相等）。
- 一键训练把「休息中」「金币不足」也算成失败。
- 赎身次数要「不同周且超过 7 天」才清零：周日把次数用完，到了下周一还是赎不了；现在按自然周清零。
- `#一键升级信用` 在升级费用倍数配成 1 时会死循环。
- 帮助里写的赎身规则（1.5 倍价格、身价变成 20%）和代码（2 倍、×1.2）对不上，按代码改。
- 购买、赎身、转账要同时改两三个人，上游一个人一个文件分几次写，中途出错或两人同时操作会对不上。现在一条语句写完，读完之后有人改过就整条不写、重算一次。

## 省额度的做法

免费版 D1 每天写 10 万行，全机器人共享。这个插件：

- 只有两张表（`players` 每群每人一行，`groups` 每群一行），都只有主键、没有二级索引，写一行就只算一行。
- **每周重置不写玩家表**：每行记着自己属于第几期，读到旧一期的行就当作刚重置过，等这个人下次真有写入时顺手覆盖。换期时只写群那一行（顺带存下上周排行榜，只留一份）。
- 查看类命令、冷却没到、钱不够等失败都不写库；一个操作写 1–3 行，一键训练写 1 行加训练到的奴隶数。冷却、银行、排位分都在玩家行的一个 JSON 字段里，不单独建表。
- 数据不会无限涨：每周一凌晨清一次 N 周（默认 4）没玩过的人和已经没人的群。每行一辈子只会被删一次。关掉每周重置时不清理。
- 换期后的上周回顾附在那一周第一条命令的回复里，走被动回复，不需要群主开主动消息权限，也不用定时推送。

## 配置

面板里的插件配置页，数值与上游 `SlaveMarket_config.yaml` 一一对应（时间按秒填），另有：

- 每周重置：开关、星期几几点几分（北京时间）、是否保留昵称、重置后的身价
- 无视冷却 / 尊贵的奴隶主：openid 名单（群里发 `/sid` 查）
- 用图片回复、市场最多展示几人、清理多少周没玩过的数据

## 开发

```bash
# QFlareBot 与本仓库并排放
git clone https://github.com/QFlareBot/QFlareBot
(cd QFlareBot && pnpm install --filter '@qqbot/plugin-cli...' && pnpm --filter '@qqbot/plugin-cli...' build)
cd qflarebot-plugin-slavemarket
npm install
npm test          # 测试用 node:sqlite 跑真实 SQL，并套用框架的表名检查
npm run typecheck
npm run sync      # 构建并更新 manifest.json
```

需要 Node 22.13 以上（`node:sqlite`）。
